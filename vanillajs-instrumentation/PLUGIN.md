# Vanilla JS Instrumentation Plugin

Instrument Vanilla JavaScript applications with Datadog RUM. Covers Vite-bundled JS apps.

## Skills

| Skill | Description |
|-------|-------------|
| `setup-vanillajs` | Vite vanilla JS app setup (meter reading PoC) |
| `vanillajs-dd-rum` | Datadog RUM integration for vanilla JS |

## Recommended Workflow

1. Run `setup-vanillajs` to scaffold the Vite-based vanilla JS application.
2. Run `vanillajs-dd-rum` to add Datadog Real User Monitoring.
