# Setup Next.js JavaScript Project

Set up a Next.js 15.5 project using JavaScript with the App Router.

## Instructions

1. Initialize a new Next.js 15.5 project with JavaScript (no TypeScript).
2. Use the App Router (not Pages Router).
3. Set up the project structure following Next.js App Router conventions:
   - `app/layout.js` - Root layout
   - `app/page.js` - Home page
   - `app/globals.css` - Global styles
4. Verify the development server starts successfully with `npm run dev`.
